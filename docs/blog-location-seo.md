# Blog location SEO rule (NorCal CARB Mobile)

Goal: every new blog post must **prove places on a map** so Google (and fleet buyers) see that NorCal CARB Mobile actually goes there.

## Required on every new post

1. **Slug includes place tokens** when the post is about a trip or corridor  
   Example: `fleets-ovi-obd-porterville-mojave`
2. **Title names ≥1 real place** (city, county, or corridor)
3. **Meta description names ≥2 places**
4. **Body names ≥3 places in plain English** (not just “our area”)
5. **At least one H2 uses a place name**  
   Example: `Porterville and Tulare County — Central Valley yards`
6. **Internal link** to `/areas` and/or the matching route page (`/central-valley-sierra-carb-testing`, `/bay-area-mobile-carb`, etc.)
7. **JSON-LD `about` / `mentions` Places** on the HTML article
8. **Optional front-matter** `locations: ["Porterville, CA", ...]` in `blog_drafts/`

## Voice

- Brand only: **NorCal CARB Mobile** (no personal names)
- Honest coverage: everyday NorCal first; fleet-asked pins (Porterville, Mojave, etc.) when asked
- Pair blog location copy with Google Business Profile photos from the same trip when available

## Do not

- Invent cities you did not visit or will not serve
- Stuff 20 city names with no sentences
- Use vague “we travel statewide” without naming pins
