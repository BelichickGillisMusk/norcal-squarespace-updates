Mid-year Clean Truck Check windows still catch fleets flat-footed. Two different tests get mixed up at the gate: the OBD scan and the OVI (opacity / visual) smoke test. Wrong assumption means a wasted slot, a failed path into CTC-VIS, or trucks sitting while you sort equipment.

What Clean Truck Check is testing for

CARB Clean Truck Check is periodic heavy-duty emissions compliance for diesel vehicles in the program — not light-duty Smog Check. In 2026, most non-exempt vehicles still run on a semi-annual testing cadence (twice a year). You can often test up to about 90 days before a compliance deadline, but the source of truth for each VIN is the fleet’s CTC-VIS account, not a blog table.

Looking ahead, OBD-equipped vehicles are expected to move toward more frequent testing in later years. Treat that as “coming,” not the only story for today’s booking.

Why fleets mix them up

  • Both show up under “Clean Truck Check” language on the same account
  • A mixed fleet can need both tests on the same day
  • Shop quotes often lump “emissions” without saying OBD vs opacity equipment
  • Deadline math uses VIN + account status — not a single calendar for every truck
